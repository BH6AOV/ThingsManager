# 盘库

盘库 = 拿实物数量与系统账面核对，并把差异一次校正到位。

## 盘库范围（V0.11.0 起可选）

页面顶部两行控制本轮盘哪些东西：

- **普通物资分类**：芯片式勾选，默认全选（全部类别）；`全选分类` / `清空分类` 一键切换。取消某个分类 → 该分类的物资不进盘点表。
- **一并入表**：`药品` / `计量器具` / `办公物资` 三个开关，**默认全部关闭**——不勾就既不进盘点表也不导出：
  - 勾选**药品 / 办公物资**：按其结存生成盘点行，提交盘库会真实校正它们的库存（等于把专项台账也纳入盘点）。
  - 勾选**计量器具**：按「每台一行」随表登记，仅用于导出 / 打印留档（计量器具没有数量模型，所以不参与库存校正）。

> 切换范围或点「↻ 恢复账面」时，如果表里已经录过实物数量，会先弹确认框，避免手工录入被静默清掉。

## 表格怎么填

| 列 | 说明 |
| --- | --- |
| 上次盘点数量 | **上次盘库的实物盘点结果**（首次盘点为 0） |
| 本次数量变化 | 实物数量 − 上次盘点数量（自动算） |
| 本次计算数量 | **固定等于实物盘点数量**（只读列，不能也不用手改） |
| 实物盘点数量 | **你只需要填这一列**：进入盘库时默认带出当前实时库存，按实物改成实际数即可 |

- 表格里的编码 / 名称 / 型号 / 类别 / 库位 / 单位 / 备注都能就地改，备注列会**自动带出物资自带备注**（没有则为空），`＋ 加手工行` 可以补录系统里没有的行。
- **动过的行整行黄底高亮**（改数量、改备注、调顺序都会），改回原值即取消——一眼就能看出这次盘了哪几行。
- 页面上有 `仅显示有库存物资` 开关：默认只显示有库存的条目，取消勾选可看到全部（含 0 库存，便于登记盘盈）。

## 盘点表顺序（V0.11.2 起可自定义）

盘库表默认按**物资编码**排列；如果货架 / 台账顺序与编码顺序不一致，可以自己定：

- `⬇ 顺序模板`：下载一份 xlsx（「盘库顺序」表，已列出全部物资），把行顺序调成实际要盘的顺序后保存。
- `⬆ 导入顺序表`：导入刚才那份 xlsx（只看「物资编码」列，多余的行 / 空行会跳过；本库没有的编码会提示并忽略）。
- **页内微调**：直接把某行的**「序号」改成想要的位置**（如把第 8 行改成 1，它就排到第一行，其余行自动顺延）；`✕` 删除该行（仅当次盘库，不影响物资档案）。
- `💾 记住当前顺序`：把当前表里的顺序固定下来，**下次盘库和导出盘点表都按它排**。
- `↺ 系统顺序`：清除自定义顺序，回到按物资编码排列。

> 顺序表里没列到的物资不会丢，会**按原顺序排在后面**。

## 提交与导出

- `✓ 提交盘点（按明细更新库存）`：生成一张**盘库单**，并把库存按实盘数字校正；SN 物资要求实盘数 = 在库 SN 数，否则会被拦下。
- `⬇ 导出盘点表`：导出 xlsx（含表头、管理单位名称、盘点人、日期与明细），**不改账面**，用于签字存档。
  - 导出范围 = 当前表里的行（含手工行），所以「盘库范围」直接决定导出内容；列顺序与行顺序**与盘库页一致**。
  - 导出表里「本次数量变化 / 本次计算数量」按导出时的实物数量重算（计算数量 = 实物数量），不会出现两列对不上的情况。
- `💾 暂存` / `📂 暂存单`：盘点做一半可以暂存，之后从首页「待我处理」继续。

## 小技巧

- 盘点前先到 `库存 & 清单` 导出清单表，照着实物逐项核对更快。
- 差异大的分类，建议先查 `单据流水` 是否有漏记 / 错记的单据，再提交盘库。
- 盘库单本身也会进 `单据流水`（类型显示为「盘库」），可以随时回看历次盘点的差异。
