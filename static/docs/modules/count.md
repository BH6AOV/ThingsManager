# 盘库

盘库 = 拿实物数量与系统账面核对，并把差异一次校正到位。

## 盘库范围（V0.11.0 起可选）

页面顶部两行控制本轮盘哪些东西：

- **普通物资分类**：芯片式勾选，默认全选（全部类别）；`全选分类` / `清空分类` 一键切换。取消某个分类 → 该分类的物资不进盘点表。
- **一并入表**：`药品` / `计量器具` / `办公物资` 三个开关，**默认全部关闭**——不勾就既不进盘点表也不导出：
  - 勾选**药品 / 办公物资**：按其结存生成盘点行，提交盘库会真实校正它们的库存（等于把专项台账也纳入盘点）。
  - 勾选**计量器具**：按「每台一行」随表登记，仅用于导出 / 打印留档（计量器具没有数量模型，所以不参与库存校正）。

> 切换范围或点「↻ 恢复账面」时，如果表里已经录过实物数量，会先弹确认框，避免手工录入被静默清掉。

## 表格怎么填

| 列 | 说明 |
| --- | --- |
| 上次盘点数量 | 上一次盘库的实盘数（首次盘点为 0） |
| 本次数量变化 | 实物数量 − 上次盘点数量（自动算） |
| 本次计算数量 | 系统账面（自动算，等于当前结存） |
| 实物盘点数量 | **你只需要填这一列**（其余列也可手工修正） |

- 页面上有 `仅显示有库存物资` 开关：默认只显示有库存的条目，取消勾选可看到全部（含 0 库存，便于登记盘盈）。
- 表格里的编码 / 名称 / 型号 / 类别 / 库位 / 单位 / 备注都能就地改，`＋ 加手工行` 可以补录系统里没有的行。

## 提交与导出

- `✓ 提交盘点（按明细更新库存）`：生成一张**盘库单**，并把库存按实盘数字校正；SN 物资要求实盘数 = 在库 SN 数，否则会被拦下。
- `⬇ 导出盘点表`：导出 xlsx（含表头、管理单位名称、盘点人、日期与明细），**不改账面**，用于签字存档。
  - 导出范围 = 当前表里的行（含手工行），所以「盘库范围」直接决定导出内容。
- `💾 暂存` / `📂 暂存单`：盘点做一半可以暂存，之后从首页「待我处理」继续。

## 小技巧

- 盘点前先到 `库存 & 清单` 导出清单表，照着实物逐项核对更快。
- 差异大的分类，建议先查 `单据流水` 是否有漏记 / 错记的单据，再提交盘库。
- 盘库单本身也会进 `单据流水`（类型显示为「盘库」），可以随时回看历次盘点的差异。
