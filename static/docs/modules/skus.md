# 物资管理

物资档案（SKU）是整套系统的主数据：出入库、盘库、清单导出都围绕它展开。

## 字段说明

| 字段 | 说明 |
| --- | --- |
| 物资编码 | 唯一标识，建议按内部规则编号；出入库与盘点表都按它排序 |
| 物资名称 / 型号 | 单据与盘点表里显示的内容，搜索也按它们匹配 |
| 物资类别 | 用于筛选、统计与盘库范围（分类在 `分类设置` 里维护） |
| 单位 | 个 / 盒 / 包 / 台 …… 开单时自动带出 |
| 存放位置 | 仓库 / 分区；出入库单的明细行默认带出它，也可逐行改 |
| SN 管理 | 勾上后该物资实行**一物一码**：出入库必须逐个填（或扫码）序列号 |
| 状态 | 停用后不出现在出入库候选与盘库范围里，但历史单据与流水不受影响 |

## 常用操作

- **搜索 / 筛选**：顶部搜索框支持编码、名称、型号；高级筛选可按类别、存放位置、单位过滤。
- **批量管理**：勾选表头复选框可全选当前列表，选中后出现操作条，可批量 **设置类别 / 设置存放位置 / 停用 / 启用 / 删除**。
  - 删除时**已有出入库流水或 SN 记录的会自动跳过**并告知原因，不会破坏账目。
- **导出**：`库存 & 清单 → ⬇ 导出清单表(xlsx)`，可带 SN、可含 0 库存项。
- **低库存提醒**：低于阈值（系统设置里配置）的物资会在首页提醒；也可按分类批量设置是否参与提醒（`低库存待关注`）。

## 两种批量建档方式

1. **盘库表开站导入**（推荐）：拿现成 Excel（编码 / 名称 / 型号 / 数量 …），一次性建档并带出初始库存。
2. **按模板导入**：`⬇ 导入模板` 下载带下拉的模板 → 填好后 `⬆ 按模板导入` → 预览无误再确认。

> 模板里的**分类、存放位置、状态三列都是下拉选项**（取系统里已设置的分类与存放位置），500 行可用，选错会拦下；下拉里没有的也能手填，导入时分类与存放位置会自动新建。

## SN（序列号）管理

- 开启 SN 管理的物资，库存数量 = **在库 SN 条数**，不能手工改成别的数字。
- `SN 管理` 页可按序列号查状态（在库 / 已出）、看它在哪张单据进来、又随哪张单据出去。
- 支持**批量出库**与**批量退回**：勾选在库 SN 直接生成出库单，退回时生成入库单回补。
- 盘库时 SN 物资的实盘数量必须等于在库 SN 数，不一致请用 SN 页核对后再提交。

## 常见疑问

- **改了物资名称 / 库位，旧单据会变吗？** 不会。单据行保存的是当时的名称与规格快照；档案修改只影响之后的新单据与候选列表。
- **能删掉物资吗？** 没有流水的可以删；有流水的只能「停用」（停用后不再出现在开单候选里，历史记录完整保留）。
