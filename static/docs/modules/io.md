# 出入库

## 开单流程

1. `出入库` 页选择 **📥 入库单** 或 **📤 出库单**（顶部切换）。
2. 填单据日期（**事后补单**就改成实际发生日期：单号里的日期段会跟着走）、供应商 / 客户（或领用部门）、经办人、备注。
3. `＋ 添加明细行`，在物资搜索框里输入**名称 / 编码 / 规格 / 库位**任意关键词，点候选选中；常用物资直接在下拉里选。
4. 填数量（SN 物资填或扫序列号，多个用换行分隔）、按行确认存放位置。
5. `保存单据` 入库 / 出库，库存立即增减。

> 保存前可点 `👁 预览` 实时渲染单据效果（可另存图片 / 导出 xlsx），**不会入账**。

## 明细行的候选条目怎么看

候选格式为 `物资编码|名称 · 型号 · 存放位置`；专项台账另有标记：

- 药品：`名称 · 批号 X · 单位 · 药品`
- 办公物资：`编码|名称 · 型号 · 单位 · 办公物资`

## 单据写完之后的几件事

- **暂存**：单据没填完可以先 `💾 暂存`，之后从 `📂 暂存单` 或首页「待我处理」继续编辑。
- **扫码 / 文件导入**：`📷 扫码 / 文件导入` 支持读取另一台设备导出的单据二维码 / 图片，或选择对方的 `.json` 文件，直接在本机入账（异地也能对账）。扫码**不再只认二维码**：商品条码（EAN-13 / UPC-A）、药品追溯码（CODE128）、CODE-39、ITF 等一维条码也能识别；扫到不是单据的内容会显示内容与格式，可复制或点「🔍 查物资 / 药品」查本机匹配结果。
- **行内扫码**：明细行里的 `📷 扫码选物资` 扫编码 / 商品条码即自动选中该物资；SN 管理物资入库用 `📷 扫码录入 SN`（连续扫，扫一个加一个，重复自动跳过），出库用 `📷 扫码勾选`（命中的在库 SN 直接勾上）。
- **xlsx 批量入库**：拿 Excel 一次性入库多条。
- **跨库流转**：`单据流水` 里对某张单点「流转」，可把该单推送到另一台已互联的仓库，对方人工确认后入账（需要先在「跨库流转」里配置互联）。

## 单据流水页能做什么

| 操作 | 用途 |
| --- | --- |
| 查看 | 看单据明细（含当时的名称 / 规格快照与 SN） |
| ✎调整 | 导出该单 xlsx 后手工调整日期 / 数量，再按模板导入 |
| ✎更正 | 改往来单位 / 经办人 / 备注（不改金额与数量） |
| xlsx / PDF | 导出打印或存档 |
| QR | 生成单据二维码，手机扫码即可查看 / 导入 |
| 撤回 | 回退该单对库存与 SN 的影响并删除单据 |

> 撤回会真实扣回 / 补回库存，请确认实物状态再操作；撤回后单据不再出现在流水里，建议先导出留档。

## 打印模板

`模板设置` 里可自定义单据版式（列顺序、列名、页眉页脚等），保存后新导出的单据即按新模板渲染。
