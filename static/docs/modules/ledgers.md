# 专项台账

除了普通物资，系统还内置了 5 类有专门管理要求的对象。它们各自独立成表，**默认不参与物资管理 / 库存清单 / 盘库**，需要时才显式纳入。

| 台账 | 特点 | 是否走库存流水 |
| --- | --- | --- |
| [计量器具](#计量器具) | 有检定有效期，到期前提醒 | 否（按台登记，仅导出留档） |
| [药品](#药品) | 批号、效期、追溯码、商品条码 | 是（结存 = 出入库流水 ± 手工调整） |
| [办公物资](#办公物资) | 日常办公用品 | 是（同上） |
| [坏件](#坏件) | 坏件登记与处置 | 处置时按借出 / 入库 / 报废办理真实单据 |
| [物资借用](#物资借用) | 借出 / 借入，带到期预警 | 是（借出开出库单、还入开入库单） |

以上五个页面都支持**勾选多条批量管理**（改类别 / 改状态 / 封存 / 删除等），删除时已有流水的条目会自动跳过。

## 计量器具

- 字段：名称、序列号、型号、存放位置、上次检测日期、有效期至、状态（在用 / 封存）。
- 到期前 90 天开始首页提醒，也进入邮件提醒（周期汇总 + 档位提醒）。
- 操作：`续期`（更新检定日期与有效期并自动解封）、`封存 / 解封`（封存后不再参与临期提醒）。
- **批量**：勾选多条可批量封存 / 解封 / 删除。
- 盘库时可把计量器具一并入表（按「每台一行」登记，仅导出留档）。

## 药品

- 字段：药品名称、物资编码、规格型号、单位、产品批号、生产日期、有效期至、入库日期、来源、**商品条码（69 码）**、**药品追溯码**、数量、状态、备注。
- **条码点开看一维码**：点商品条码或追溯码的数字即可弹出对应一维码（69 码按 EAN-13、追溯码按 CODE128，12 位数字自动补校验位），可对着屏幕用扫码枪核对；追溯码弹窗里提示「请使用支付宝扫码验证药品信息」。
- **📷 扫码填入**：商品条码 / 追溯码输入框旁的 `📷` 按钮可用手机摄像头直接扫码填入（一维条码与二维码都行，`▥` 按钮仍是本地预览一维码）；扫到的商品条码若已被别的药品使用会立即提示。
- **追溯码唯一**：一盒一码；填了别的药品已用的追溯码会被拦下并指出占用方（按模板导入时重复行自动跳过）。
- **数量**以出入库单为准，也可以在「编辑」里直接改（记下手动调整量，两项互不覆盖）；填了追溯码时新增默认数量 1。
- **停用**：停用后默认不在本页显示（可勾「显示已停用」找回），出入库单选不到，历史单据与流水不受影响。
- 同一药品**不同批次请分条录入**（批号即识别码，各批次数量独立核算）。
- **导出**：`⬇ 导出清单`（页面所见范围）+ `📋 出入库记录`（指定时间段内的全部药品进出明细，自带入库 / 出库 / 净变化合计）。

## 办公物资

- 新增时若未选类别，会自动归到 **「办公物资」分类**。
- 可像普通物资一样在 `出入库` 页做出入库（候选中标着「办公物资」）；数量 = 出入库流水 ± 手工调整。
- 支持批量设置类别 / 存放位置 / 停用启用 / 删除，以及 `📋 出入库记录` 一键导出。
- 需要盘点时，在 `盘库` 页勾上「办公物资」即可一并按结存盘点。

## 坏件

登记坏件（条目取自「物资管理」档案，名称 / 规格 / 单位 / 库位自动带出）、记录坏件原因与处理进度，并可**直接办处置**：

| 处置 | 账务动作 | 结果 |
| --- | --- | --- |
| **送修** | 按**借出**办理：开出库单 + 生成借用台账（借用人 = 维修方，可填应还日） | 状态 → 维修中；库存已减，可在「物资借用」页跟进 |
| **已修复** | 按**入库**办理：开入库单并结清送修借用 | 状态 → 已修复；库存回补 |
| **丢弃** | 按**出库报废**办理（真减库存，需库存足够） | 状态 → 已报废 |
| **停用** | 只标记该坏件记录不再处理 | 状态 → 已停用；不动库存与单据 |

- 处置生成的单据号会显示在备注旁边，点单号可直接查看该单据。
- 送修未修复前不能直接丢弃（会提示先办理「已修复」或到借用页归还），避免账实不符。
- 普通「状态」推进（待处理 → 维修中 → 已修复 → 已报废）用「进度」按钮即可，不需要单据时用它标记即可。

## 物资借用

- **借出**（本库物资借给别人）/ **借入**（别人借给本库）都走真实出入库：借出开出库单、借入开入库单。
- 未填应还日但填了借期时，系统会按「借用日期 + 借期」自动推算应还日。
- 到期预警：超期为淡红、≤3 天淡橙、≤7 天淡黄；首页与邮件提醒都会列出超期未还。
- `归还` 可一次勾选多条同向记录合并成一张单据办理结清。

## SN 追踪

- 一物一码：SN 物资的库存 = 在库 SN 条数。
- 支持按号码查询状态与历史单据，支持纠选在库 SN 批量出库、已出 SN 批量退回。
