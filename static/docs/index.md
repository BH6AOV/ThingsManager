# ThingsManager 使用文档

一套**开箱即用**的轻量仓库管理系统：出入库、盘库、清单导出、SN 追踪、专项台账（计量器具 / 药品 / 办公物资 / 坏件 / 借用）、邮件提醒与数据安全备份。所有数据都在本机 SQLite 里，不依赖外网。

> 本文档站的内容就是 `static/docs/` 下的 Markdown 文件，改完刷新页面即可看到效果，无需重新构建。

## 三步上手

1. **建档**：`物资管理` 里把要管的物资登记好（也可用「⬆ 盘库表开站导入」按模板批量导入）。
2. **记账**：日常进出走 `出入库` 页开单（入库 / 出库），库存自动增减。
3. **盘库 + 备份**：定期到 `盘库` 页核对实物并按实盘更新库存；到 `系统设置 → 数据维护` 打开**每日定时备份**（完整数据包 zip）。

## 数据放在哪里？

- **默认数据目录**：程序目录下的 `data/`（安装版为 `%ProgramData%\ThingsManager\data`）。
- 里面是 `warehouse.db`（SQLite 数据库）、`templates/`（自定义打印模板）、`brand/`（Logo 与登录背景）、`backup/`（备份）、`edition.json`（版本特化配置）。
- **升级程序不影响数据**：换包只替换程序文件，数据目录不会被改动。
- 备份 / 换机 / 恢复的完整说明见 [系统设置 · 数据维护](modules/settings.md)。
