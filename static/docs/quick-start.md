# 快速上手

第一次用，按下面顺序走一遍就能跑通全流程（大约 10 分钟）。

## 1. 基础设置（系统设置 → 常规）

| 设置项 | 说明 |
| --- | --- |
| 实例名 / 管理单位名称 | 显示在侧栏、浏览器标题、打印单据上 |
| 默认经办人 / 默认供应商 / 默认存放位置 | 开单时自动带出，可逐单修改 |
| 常用单位 / 客户 / 领用部门 / 借用人 | 开单时的下拉候选，仍可手输 |
| 低库存阈值 | 低于该数量的物资在首页提醒 |

## 2. 存放位置与分类

- `分类设置` 里维护**物资类别**（如 办公用品 / 劳保用品 / 维修配件）与**存放位置**（仓库 → 分区两级）。
- 分类与存放位置都能用「⬇ 导入模板」批量登记，模板里已带系统内已有的下拉选项。

## 3. 建物资档案

- `物资管理 → ＋ 新建物资`：编码、名称、型号、类别、单位、存放位置；需要一物一码的勾上 **SN 管理**。
- 批量建档推荐：`物资管理 → ⬆ 盘库表开站导入`，用现成的 Excel 台账（编码 / 名称 / 数量 …）一次导入并带出初始库存。
- 已有台账也能用 `⬆ 按模板导入`：模板里的**分类、存放位置、状态都是下拉**，选错会被拦下。

## 4. 日常记账

- `出入库 → 📥 入库单`：选日期、供应商、经办人，明细行里搜索物资（输入名称 / 编码 / 规格 / 库位都能搜到），填数量，保存。
- `出入库 → 📤 出库单`：同上，客户 / 领用部门可下拉选常用单位。
- 单据保存后库存自动增减；`保存单据` 前可点 `👁 预览` 看打印效果。

> 单据写错了？到 `单据流水` 找到那张单，可以「✎更正」（往来单位 / 经办人 / 备注）、「✎调整」（导出后改数量）、或「撤回」（回退它对库存与 SN 的影响）。

## 5. 盘库

- `盘库` 页顶部可选**盘库范围**：按分类勾选本轮盘哪些物资；`药品 / 计量器具 / 办公物资` 默认不参与，需要时勾上即可。
- 表格里逐行录 **实物盘点数量**，`本次计算数量` 与`本次数量变化`自动算；有备注的会自动保留。
- `✓ 提交盘点` 会生成一张盘库单，并把库存按实盘数字校正；也能只`⬇ 导出盘点表`存档。

## 6. 打开数据安全

- `系统设置 → 数据维护`：
  - 打开**每日定时备份**（生成完整数据包 zip：数据库 + 模板 + 品牌 + 版本特化配置）。
  - 需要还原时用 `🛠 从数据库文件恢复` 或数据包导入，**不要手工把备份文件拷进数据目录覆盖**（那会让数据库打不开）。
- 换机器：把数据包拷过去 → 新机器上「导入全部数据」即可。

## 7. 可选：邮件提醒

- `系统设置 → 邮件通知` 填 SMTP 账号，打开**周期提醒**（临期 / 过期 / 借用超期汇总）与**到期档位提醒**（如提前 90 / 30 / 7 / 3 / 1 天各提醒一次）。
- 漏发了可以一键**手工补发**，还能指定日期补发某一天应有的提醒。
