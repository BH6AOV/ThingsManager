# 常见问题

## 程序打不开 / 页面一直转圈

1. **浏览器缓存**：先强制刷新（Windows `Ctrl+F5`）。界面脚本带版本号，正常会自动更新。
2. **端口被占用**：默认端口 `3200`（安装版）。检查是否有另一个实例在运行。
3. **数据库打不开**：如果你曾把备份文件直接拷进数据目录覆盖 `warehouse.db`，就会这样。新版启动时会自动隔离作废的日志，程序可以照常起来；随后请到 `系统设置 → 数据维护 → 🛠 从数据库文件恢复` 正式还原数据。

## 数据存在哪？怎么换机器？

- 默认数据目录：程序目录下的 `data/`（安装版为 `%ProgramData%\ThingsManager\data`）。
- 换机器：`系统设置 → 数据维护 → 📦 导出全部数据` → 在新机器上 `📥 导入全部数据`。
- 只想要业务数据：用一个 `.db` 备份文件走 `🛠 从数据库文件恢复`。

## 能直接删数据目录里的文件吗？

可以删 `backup/` 里的旧备份、`logs` 之类的临时文件；**不要**动 `warehouse.db`、`-wal` / `-shm`，也不要在程序运行时手工替换数据库文件。

## 为什么盘库里看不到药品 / 计量器具 / 办公物资？

它们默认不参与盘库（各自是独立台账）。到 `盘库` 页顶部勾上 `药品` / `计量器具` / `办公物资` 即可一并入表：

- 药品 / 办公物资：按结存生成盘点行，提交盘库会真实校正库存。
- 计量器具：按「每台一行」随表登记，仅用于导出留档。

## 药品 / 办公物资为什么不在「物资管理」里？

它们是**专项台账**，各自有独立页面，默认不进物资管理、库存清单与盘库（避免和日常物资混在一起统计）。但它们的**库存是真实的**：可以在 `出入库` 页搜到它们并开单，结存 = 出入库流水 ± 手工调整。

## 数量对不上怎么办？

1. 到 `单据流水` 按物资或时间段查该物资的历史单据，确认是否有漏记 / 错记 / 撤回。
2. 确认无误后到 `盘库` 页把它盘出来（实盘为准），提交后库存即校正。
3. 药品 / 办公物资也可以直接在「编辑」里改数量（会记作手工调整量，流水照算）。

## SN 物资为什么不允许改数量？

SN 物资的库存等于**在库序列号条数**，数字由 SN 决定。请到 `SN 管理` 页处理：入库生成 / 录入 SN、出库勾选 SN、退回勾选已出 SN，数量会自动跟随。

## 上传的 Logo 没生效？

- Logo 与登录背景有格式（PNG / JPG）与尺寸要求，上传前会提示；
- 生效范围：侧栏、浏览器标题、登录页、**标签页图标**；清掉自定义 Logo 会回落到版本特化 / 内置 Logo；
- 若只是标签页图标没变，强制刷新页面（`Ctrl+F5`）再看。

## 想改打印单据的版式

`模板设置` 里改：列顺序、列名、页眉页脚都能自定义，改完保存，之后导出的单据按新模板渲染。改坏了可以「恢复默认模板」。

## 邮件没收到 / 发送失败

1. 先在 `系统设置 → 邮件通知` 点 `✉ 发送测试邮件`，看报错信息（常见是授权码错误、端口或 SSL 选错、收件人未配置）。
2 . 检查「发送 / 漏发记录」：绿色=已发送、蓝色=已检查但当天无内容、红色=失败 / 漏发。
3. 漏发时用 `🔄 手工补发` 立即补一次，也可以指定日期补发。

## 多台电脑能否共用一个库？

支持两种玩法：

- **互联仓库**：各自独立数据库，通过「跨库流转」把单据推给对方，对方确认后入账（适合异地 / 上下级）。
- **共享数据目录**：让多个实例指向同一个数据目录（`系统设置 → 数据目录`），同一时刻只让一个实例写入。

## 升级会丢数据吗？

不会。升级只替换**程序文件**，数据目录（含数据库、模板、品牌、`edition.json`）保持不动。升级前建议先导出一个完整数据包。

## 还有别的问题？

把「系统日志」里对应的报错（或时间点）发出来即可定位。
